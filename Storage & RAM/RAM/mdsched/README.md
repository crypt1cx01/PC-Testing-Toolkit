### 4. Windows Memory Diagnostic (Built-in Quick RAM Test)
* **Purpose:** Built-in Windows utility to check your system memory for hardware problems without needing external tools or USB flashing.
#### 🚀 Method 1: The Quickest Way (Recommended)
1. Press `Windows Key + R` on your keyboard to open the **Run** dialog box.
2. Type or paste the following command and press Enter:
   ```cmd
   mdsched.exe
   ```
3. Choose **"Restart now and check for problems (recommended)"**.

#### 🛠️ Method 2: Via Control Panel (Alternative)
1. Open the **Control Panel** and set *View by* to **Large icons**.
2. Click on **Administrative Tools** *(Called **Windows Tools** on Windows 11)*.
3. Double-click on **Windows Memory Diagnostic**.
4. Choose **"Restart now and check for problems (recommended)"**.

---
* **Note:** Your PC will restart immediately into a blue diagnostic screen and start testing your RAM automatically. Save all your open work before clicking restart!
