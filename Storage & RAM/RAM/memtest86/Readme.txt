1 ) عايزين فلاشه فاضيه
2 ) تحميل الأداة مجانًا من موقعها الرسمي: MemTest86 Download (اختر نسخة Free Edition).

الخطوة 1: حرق الأداة على الفلاشة
1 ) قم بفك الضغط عن الملف الذي قمت بتحميله.
2 ) قم بتوصيل الفلاشة بالكمبيوتر.
3 ) افتح برنامج imageUSB.exe المرفق داخل الملف المضغوط.
4 ) حدد الفلاشة الخاصة بك من القائمة العليا.
5 ) اضغط على زر Write وانتظر حتى ينتهي (ستتحول الفلاشة إلى أداة إقلاع ذاتي).

الخطوة 2: الإقلاع من الفلاشة (Boot)
1 ) أعد تشغيل الكمبيوتر المراد فحصه.
2 ) بمجرد ظهور شعار الشركة (بوردة الجهاز)، اضغط بشكل متكرر على زر قائمة الإقلاع Boot Menu (غالباً يكون F12 أو F11 أو F8 أو F9 حسب نوع جهازك).
3 ) اختر فلاشة الـ USB من القائمة لتفتح لك واجهة برنامج MemTest86.

الخطوة 3: بدء الفحص (The Test)
1 ) بمجرد فتح الواجهة، سيبدأ الاختبار تلقائيًا بعد 10 ثوانٍ، أو يمكنك الضغط على (T) Start Test للبدء فورًا.
2 ) ستقوم الأداة بـ 4 دورات فحص كاملة (Passes) تكتب وتقرأ فيها بيانات معقدة على الرام للتأكد من سلامتها.
3 ) ملاحظة: الفحص يأخذ وقتًا طويلًا (من ساعة إلى عدة ساعات حسب حجم وسرعة الرامات لديك).

كيف تقرأ النتيجة
اللون الأخضر (PASS): إذا انتهى الفحص وظهرت عبارة "Pass" باللون الأخضر وعدد الأخطاء (Errors: 0)، فهذا يعني أن الرامات سليمة 100% ومستقرة.
اللون الأحمر (FAIL): إذا ظهرت أي أسطر باللون الأحمر أو زاد عداد الـ Errors عن (0)، فهذا يعني أن الرام بها عيب مصنعي أو تالفة، وهي السبب في تهنيج الجهاز أو ظهور الشاشات الزرقاء، ويجب تغييرها فورًا.
