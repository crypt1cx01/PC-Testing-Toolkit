# 💽 Storage & RAM Diagnostic Suite

Ensure your storage drives (SSD/HDD) are healthy and that your system RAM is stable without memory leaks.

## 🛠️ Included Tools

### 1. CrystalDiskInfo
* **Download:** [CrystalDiskInfo ZIP](https://crystalmark.info)
* **Usage:** Displays S.M.A.R.T health status. Look at **Health Status** (should be Good) and **Power On Hours** to know the device's real age.

### 2. CrystalDiskMark
* **Download:** [CrystalDiskMark ZIP](https://crystalmark.info)
* **Usage:** Tests sequential read/write speeds of your drives to confirm they match factory specifications.

### 3. MemTest86
* **Download:** [MemTest86 Free Edition](https://memtest86.com)
* **Usage:** Flash to a USB drive using the included `imageUSB` tool. Boot your computer from the USB to run an absolute RAM test before loading Windows. 0 errors mean your RAM is completely safe.
