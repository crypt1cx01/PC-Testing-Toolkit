# 🔌 Peripherals & Port Validation

Quick web tools to check input/output responses and external hardware ports.

## 🛠️ Web Diagnostic Shortcuts

* **Keyboard Tester:** [Keyboard Tester](https://keyboardtester.com) - Press all keys to make sure they register properly.
* **Webcam Test:** [Webcam Test](https://webcamtests.com) - Check camera resolution and frame stability.
* **Mic Test:** [Mic Tests](https://mictests.com) - Record and playback audio to check microphone clarity.
